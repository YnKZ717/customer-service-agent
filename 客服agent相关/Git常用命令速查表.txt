========================================
  Git 版本控制常用命令速查表
========================================


┌──────────────────────────────────────────┐
│  一、本地 Git 基本命令                    │
└──────────────────────────────────────────┘

git init
  → 初始化一个新的 Git 仓库（在项目目录下执行一次即可）

git status
  → 查看当前工作区状态，显示哪些文件被修改了、哪些还没提交

git add .
  → 把所有修改过的文件放进"暂存区"（准备提交）

git add 文件名
  → 只把指定的一个文件放进暂存区

git commit -m "说明文字"
  → 正式提交快照，引号里写这次改了什么（必须写）

git log
  → 查看所有提交历史（按 q 退出）

git log --oneline
  → 简洁模式查看提交历史（一行一条）

git diff
  → 查看当前修改了什么内容（还没 add 的改动）

git diff --cached
  → 查看暂存区里待提交的内容

git checkout .
  → 撤销所有未提交的修改（危险，会丢失改动）

git checkout 文件名
  → 撤销指定文件的未提交修改

git reset --hard HEAD
  → 回退到最新一次提交的状态（危险，会丢失所有未提交改动）

git reset --hard 提交编号
  → 回退到指定快照（提交编号从 git log 里复制）

git stash
  → 临时保存当前修改（不提交，先放着）

git stash pop
  → 恢复之前临时保存的修改


┌──────────────────────────────────────────┐
│  二、分支管理命令                         │
└──────────────────────────────────────────┘

git branch
  → 查看所有本地分支

git branch 分支名
  → 创建一个新分支

git checkout 分支名
  → 切换到指定分支

git checkout -b 分支名
  → 创建新分支并立即切换过去

git branch -d 分支名
  → 删除指定分支

git merge 分支名
  → 把指定分支合并到当前分支


┌──────────────────────────────────────────┐
│  三、GitHub 远程仓库命令                  │
└──────────────────────────────────────────┘

git remote add origin 仓库地址
  → 把本地仓库关联到 GitHub 上的远程仓库（只需执行一次）
  → 仓库地址格式：https://github.com/用户名/仓库名.git

git remote -v
  → 查看已关联的远程仓库地址

git push -u origin main
  → 第一次推送代码到 GitHub 的 main 分支（只需加 -u 一次）

git push
  → 以后推送代码都用这个（把本地提交推到 GitHub）

git pull
  → 从 GitHub 拉取最新的代码到本地（别人改了代码时用）

git clone 仓库地址
  → 从 GitHub 下载一个仓库到本地（第一次拿到项目时用）

git branch -M main
  → 把当前分支改名为 main（GitHub 默认主分支叫 main）


┌──────────────────────────────────────────┐
│  四、日常开发完整流程                     │
└──────────────────────────────────────────┘

第1步：改代码
  → 用编辑器修改文件

第2步：查看改了什么
  git status

第3步：放进暂存区
  git add .

第4步：提交快照
  git commit -m "改了xxx功能"

第5步：推到 GitHub
  git push


┌──────────────────────────────────────────┐
│  五、第一次使用 GitHub 的完整流程          │
└──────────────────────────────────────────┘

1. 在 GitHub 上创建新仓库（网页操作）
2. 回到终端执行：
   git remote add origin https://github.com/用户名/仓库名.git
   git branch -M main
   git push -u origin main
3. 以后每次改完代码只需：
   git add .
   git commit -m "说明"
   git push


┌──────────────────────────────────────────┐
│  六、常见问题解决                         │
└──────────────────────────────────────────┘

推送失败 "failed to push"
  → 先执行 git pull，解决冲突后再 git push

推送失败 "Connection was reset"
  → 网络问题，等一会儿再试 git push

"nothing to commit"
  → 没有新改动，不用提交

"not a git repository"
  → 没在项目目录下执行，先 cd 到项目目录

忘记密码/Token 过期
  → 重新登录 GitHub 授权，或去 GitHub Settings 生成新 Token


┌──────────────────────────────────────────┐
│  七、git克隆远程仓库到本地                  │
└──────────────────────────────────────────┘
1. 打开终端（Git Bash / CMD / PowerShell）

2. 进入你想存放项目的目录：
   cd 目标路径

3. 执行克隆命令：
   git clone 仓库地址

4. 进入克隆下来的项目：
   cd 仓库名

5. 以后改完代码只需：
   git add .
   git commit -m "说明"
   git push
